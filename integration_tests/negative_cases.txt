#
#   macro | expected error text | [value for --vars]

# output contains the expected text. Matching the message (not just the exit code) means a case can't
# pass because of a typo in the test itself or an unrelated error. The script also fails if a macro in
# assert_rejected.sql is missing from this file, or a line here has no macro, so nothing goes unrun.
